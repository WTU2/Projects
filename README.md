To use this app, simply run mediaProcessingApp.exe, and there will be two buttons:
1.) Select Video
	- This button will open a directory for you to select a .mp4 file
2.) Convert
	- This button will convert the .mp4 file to an .mp3 file
3.) Trimming
	- This button will trim the same file type to the user's specified start and end time
	- Arrow keys allowed for more precise trimming to the user's liking
I have packaged two test .mp4 files, feel free to use them, otherwise, you are free to use any other .mp4 files.
